What is an L1 Support Engineer?

An L1 Support Engineer (Level-1 Support) is the first point of contact for users facing IT issues.
Main job: Receive tickets → Identify issue → Fix basic problems → Escalate complex issues to L2

Example issues handled:

Password reset
Outlook not opening
Printer not working
Internet issue
Software installation
System slow
Step-by-Step Topics with Practical Learning Guide
1️⃣ Basic Networking (Must for L1 Support)
What you should know

Core concepts:

IP Address
DNS
DHCP
LAN / WAN
Default Gateway
Ping command
ipconfig command
Practical Practice (Do this on your system)

Open Command Prompt and try:

ipconfig

Shows your system IP address

Checks internet connectivity

Shows full network details

Real Office Example

User says:

Internet not working

You check:

Step 1 → Check cable connected
Step 2 → Run ping command
Step 3 → Restart network adapter
Step 4 → Restart system
Step 5 → Escalate if still issue

Interview Tip (Very Important)

If interviewer asks:

What does L1 Support Engineer do?

Answer:

L1 Support Engineer is the first level of technical support responsible for handling basic IT issues like password reset, Outlook issues, software installation, printer problems, network connectivity troubleshooting, Active Directory user management, and ticket handling using tools like ServiceNow.


🧑‍💻 How to Practice Basic Networking at Home (Step-by-Step)
1️⃣ Practice IP Address (Check your system IP)
Steps:
Press Windows + R
Type cmd
Run command:
ipconfig

You will see:

IPv4 Address → Example: 192.168.1.5
Subnet Mask → Example: 255.255.255.0
Default Gateway → Example: 192.168.1.1

📘 What this means:

IPv4 = Your device address in network
Subnet Mask = Network size
Gateway = Router address
