What is an L1 Support Engineer?

An L1 Support Engineer (Level-1 Support) is the first point of contact for users facing IT issues.
Main job: Receive tickets → Identify issue → Fix basic problems → Escalate complex issues to L2

Example issues handled:
Password reset
Outlook not opening
Printer not working
Internet issue
Software installation
System slow

Interview Tip (Very Important)

If interviewer asks:

What does L1 Support Engineer do?

Answer:

L1 Support Engineer is the first level of technical support responsible for handling basic IT issues like password reset, Outlook issues, software installation, printer problems, network connectivity troubleshooting, Active Directory user management, and ticket handling using tools like ServiceNow.

Swagger 

Swagger એ API ને samajva, test karva ane document karva માટેનું tool છે.
Simple language માં:
જો Backend Developer API બનાવે છે, તો Swagger તમને બતાવે છે:
API URL શું છે
કઈ API available છે (/login, /signup, /users…)
કયો HTTP method use કરવો (GET, POST, PUT, DELETE)
Request માં શું મોકલવું
Response માં શું મળશે
API test કેવી રીતે કરવી

1. Real Example
માનો backend developer એ તમને Swagger link આપી:
Plain text
https://api.example.com/swagger
તમે open કરો તો તમને API list દેખાશે.
Example:
Plain text
POST /auth/signup
POST /auth/login
GET /users/profile


2. Login API Example
Swagger માં આવું દેખાઈ શકે:
POST /auth/login
Request Body:
JSON

{
  "email": "user@gmail.com",
  "password": "123456"
}
Response:
JSON
{
  "success": true,
  "token": "abc123xyz"

એનો અર્થ:
Frontend માં તમારે email + password મોકલવાનું.
જો login success થાય → backend તમને token આપશે.
