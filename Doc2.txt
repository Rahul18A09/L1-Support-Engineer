

Domain name એટલે તમારી website નું internet પરનું address.
ઉદાહરણ:
google.com → Google નો domain
amazon.in → Amazon નો domain
aviation.com → તમારી flight booking website નો domain

સરળ ભાષામાં:
Website = તમારું ઘર
Hosting Server = જમીન જ્યાં ઘર બનાવ્યું છે
Domain = ઘરના address જે લોકો search કરે છે

🛸CI/CD Pipeline
CI/CD Pipeline is a process that helps developers automatically build, test, and deploy code whenever changes are made.

What does CI/CD mean?
1. CI (Continuous Integration)

When developers push code to GitHub, the system automatically:

Downloads the latest code
Installs dependencies
Runs tests
Checks for errors
Builds the projects

2. CD (Continuous Delivery / Continuous Deployment)

After CI succeeds:
The application is deployed automatically
Server gets the latest code
Website is updated without manual work
